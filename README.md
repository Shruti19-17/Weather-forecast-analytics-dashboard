# 🌦️ Weather Forecast Analytics Dashboard

## 📌 Project Overview

This project is an interactive Weather Analytics and Forecasting Dashboard designed to analyze and visualize current weather conditions along with hourly and daily forecasts.

The project combines weather data from multiple sources and presents key insights through interactive dashboards, making it easier to understand temperature, humidity, rainfall, wind conditions, and weather trends across different locations and time periods.

## 📊 Key Features

- 🌡️ Current temperature and weather conditions
- 🌤️ Day and night weather analysis
- 💧 Humidity monitoring
- 🌧️ Rainfall and precipitation analysis
- 💨 Wind speed and direction analysis
- 📍 Location-based weather insights
- 📅 Daily weather forecasting
- ⏰ Hourly weather forecasting
- 🌡️ Minimum, maximum, and average temperature analysis
- 📈 Weather trend visualization

## 📁 Dataset

The project uses multiple Excel datasets:

- `Current.xlsx` – Current weather conditions
- `Forcast_Hour.xlsx` – Hourly weather forecast data
- `Forcast_Day.xlsx` – Daily weather forecast data
- `MasterReport.xlsx` – Combined dataset used for dashboard reporting

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power BI
- Data Cleaning
- Data Transformation
- Data Visualization
- Dashboard Design

## 📈 Dashboard Insights

The dashboard provides a consolidated view of:

- Current weather conditions
- Temperature trends
- Humidity levels
- Rainfall patterns
- Wind conditions
- Hourly forecasts
- Daily forecasts
- Location-wise weather information

## 🎯 Objective

The main objective of this project is to transform raw weather forecast data into an interactive and easy-to-understand dashboard that can support quick weather analysis and decision-making.
